Архитектура и возможности

Всё необходимое для бесперебойной работы с LLM

Шлюз решает ключевые боли разработчиков: лимиты скорости, перегрузку квот, обрывы стримов и сложную настройку.

Standalone EXE (1 файл)

Скачал и запустил. Включает упакованный React Web UI, иконку, дефолтные OAuth ключи и встроенную SQLite базу данных. Никакого Node, Python или pip.

Умный пул аккаунтов

Подключайте десятки Google-аккаунтов в один пул. При достижении 429 лимита шлюз мгновенно и прозрачно ротирует аккаунты, суммируя их квоты.

Изоляция прокси для аккаунтов

Каждый аккаунт может иметь свой собственный HTTP/SOCKS5 прокси. Все запросы квот, refresh токенов и стриминга идут строго через его прокси без утечек.

Clean Stream Retry

Никаких сообщений с текстом «Error: Connection...» от имени модели. При сетевой ошибке стрим обрывается на уровне TCP/HTTP, заставляя Claude Code или Cursor делать чистый ретрай.

Инспектор запросов & HAR

Полный лог активности: исходные промпты, сырые ответы Google, токены, задержка, ошибки и экспорт логов для отладки любых AI-интеграций.

Менеджер API-ключей

Создавайте мастер-ключи или ограниченные ключи с лимитами токенов и сроком жизни для безопасной раздачи коллегам или друзьям.

Запуск Standalone .EXE

  1. Скачайте файл agy2api.exe со страницы последнего релиза.
  2. Запустите файл двойным кликом — в браузере автоматически откроется веб-панель управления http://127.0.0.1:26767.
  3. Нажмите «Добавить аккаунт» в веб-панели и авторизуйте один или несколько Google-аккаунтов.
  4. Готово! Шлюз запущен и принимает запросы на портах OpenAI и Anthropic API.

Использование с официальным Claude Code (CLI)

Настройте переменные окружения терминала для работы Claude Code через шлюз:

# Windows (PowerShell):
$env:ANTHROPIC_BASE_URL="http://127.0.0.1:26767/anthropic"
$env:ANTHROPIC_API_KEY="agy-secret-key-12345"
claude --dangerously-skip-permissions
# Linux / macOS (Bash):
export ANTHROPIC_BASE_URL="http://127.0.0.1:26767/anthropic"
export ANTHROPIC_API_KEY="agy-secret-key-12345"
claude --dangerously-skip-permissions

Вопросы и ответы

Часто задаваемые вопросы

Нужна ли платная подписка Google AI Studio или Google Cloud? ▼

Нет! AGY2API использует официальные бесплатные квоты, выделяемые для Antigravity CLI. Вы можете использовать стандартные бесплатные аккаунты Google без привязки банковских карт.

Как работает автоматический обход лимитов (429 Rate Limit)? ▼

Когда аккаунт временно исчерпывает 5-часовой или недельный лимит запросов, шлюз помечает его статус как cooldown до момента сброса квоты Google и автоматически переключает запросы на следующий активный аккаунт из пула без прерывания пользовательской сессии.

Безопасно ли хранятся токены аккаунтов? ▼

Да. Токены хранятся исключительно локально на вашем компьютере в изолированной базе SQLite (data/stats.db) и файле манифеста. Данные никогда не отправляются на сторонние серверы.

Можно ли использовать свои прокси для разных аккаунтов? ▼

Да, в веб-интерфейсе для каждого аккаунта есть иконка редактирования прокси. Вы можете привязать индивидуальный HTTP или SOCKS5 прокси (с логином и паролем) к каждому аккаунту отдельно.
