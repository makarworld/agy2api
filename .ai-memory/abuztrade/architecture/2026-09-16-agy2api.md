**内容**: AGY2API — FastAPI шлюз для Google Antigravity & Cloud Code Assist (Gemini 3.7 / Flash Thinking) через форматы OpenAI и Anthropic API.
Поддерживает:
- Пул аккаунтов Google с ротацией при 429 Rate Limit
- Прокси на каждый аккаунт
- Веб-дашборд управления (FastAPI + React UI)
- Транспорт HTTP к daily-cloudcode-pa.googleapis.com
- OAuth refresh токенов Google Antigravity

**影响**: Все модули app/ (api, core), UI, тесты
